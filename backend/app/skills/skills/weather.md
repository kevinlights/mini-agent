# Weather Skill

This skill provides current weather information for any location worldwide.

## Capabilities

- Current temperature and conditions
- Weather forecast
- Humidity and wind information

## Usage

Ask about weather in any city or location. The skill will provide current conditions.

## Examples

- "What's the weather in Tokyo?"
- "Tell me the weather in London"
- "Is it raining in New York?"

## How to Run

```bash
# mockup with random weather conditions
python -c "import random; print(random.choice(['sunny', 'cloudy', 'rainy', 'snowy']))"
```
